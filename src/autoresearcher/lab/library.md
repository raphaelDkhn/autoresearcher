# Library

Lessons about how to research this problem: at most one per review, each backed by runs.
Before proposing changes in a review, read the entries whose cue matches your situation. A
lesson from an older window is a hypothesis now: check it against recent runs.

Entry format:

    ## <short title> (review after #<run id>)
    cue: the shape of situation it applies to, not this window's facts
    lesson: the change to make, naming the lab/ file it concerns
    evidence: the review rows and runs it rests on
    confidence: high, medium, or low, and why
